# KiCad設計

`MicroKeyboard.kicad_pro`を開きます。`sym-lib-table`と`fp-lib-table`にプロジェクト専用ライブラリを登録しています。

KiCad 10で開いてください。回路図とPCBにAE-XCL103-3V3をU1、XIAO nRF52840（ピンなし表面実装）をU2として配置しています。現在は部品登録段階で配線がなく、基板外形も未確定です。寸法・端子対応・BOMは`../../docs/components/ae_xcl103_3v3.md`を参照してください。

XIAOの端子と3Dモデルの出典・変更は[部品資料](../../docs/components/xiao_nrf52840.md)を参照してください。
